# Changelog

All notable changes are documented here. The project follows semantic versioning after the experimental `0.1.x` line.

## 0.1.0 - 2026-08-11

- Extracted content-production, free-production, publish-engine, platform-protocol, and AI-provider packages.
- Added a standalone MCP publishing server.
- Persisted MCP job payloads and results across process restarts.
- Added build artifacts, package entry-point checks, security guidance, and open-source documentation.
- Replaced host-specific default branding and media protocol names with configurable project-neutral equivalents.
