# Live publishing authorization

Real publishing is an explicit operator-controlled action. Before enabling an executor, record that the operator:

- owns or is authorized to operate the platform account;
- approves the selected official API or browser automation method;
- approves one non-sensitive live test article;
- approves public URL and post-publish liveness verification;
- understands that CAPTCHA, device confirmation, and security challenges always require human takeover.

The engine never stores cookies in its repository and never bypasses platform security challenges. Keep authorization records and credentials outside the repository.
